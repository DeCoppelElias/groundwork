# Taskboard

A single-user task board in the browser.

This file is the glossary and nothing else: each word the project uses for its
own concepts, defined in a sentence or two, with the words to avoid. No
implementation, no decisions, no code. A general programming term does not
belong here.

## Language

**Card**:
One task on the board, with a title.
_Avoid_: ticket, item

**Column**:
One of the three stages a card sits in: to do, doing, done.
_Avoid_: lane, list

**Board**:
All the columns and their cards, as the user sees them.
_Avoid_: project, workspace
