# Workflows

Approvals and preferences are lines in AGENTS.md. A workflow becomes a skill
only when an eval shows a fresh agent with AGENTS.md alone gets it wrong, and
the lightest fix is tried first: a sharper AGENTS.md line, then a skill.
Skills cost context in every session and drift from the documents they
describe, so each has to earn its place.

A grill writes nothing until it ends, then sends a summary and applies the
changes after the owner says go. Grilling itself uses mattpocock's
`grill-with-docs` rather than a groundwork skill.
